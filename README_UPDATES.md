# Що змінено в цій збірці Jarvis

Базовий проєкт: https://github.com/RustamovAkrom/JARVIS
Плюс: короткі голосові семпли (`assets/voice/*.wav`) і модель
`vosk-model-small-ru-0.22`, взяті з твого варіанту `JARVIS_BETA.exe`.

## 1. Легко додавати команди без коду

Файл **`custom_commands.yaml`** (у корені проєкту) — додаєш команди
просто текстом, кодити нічого не треба:

```yaml
- phrases:
    - "відкрий гмейл"
    - "пошта"
  type: "url"
  value: "https://mail.google.com"

- phrases:
    - "запусти фотошоп"
  type: "path"
  value: "C:/Program Files/Adobe/Photoshop/Photoshop.exe"

- phrases:
    - "розкажи анекдот про програмістів"
  type: "say"
  value: "Скільки програмістів треба, щоб закрутити лампочку? ..."
```

Три типи дій:
- `url` — відкрити сайт
- `path` — відкрити файл / папку / програму (повний шлях)
- `say` — просто сказати фразу

Файл автоматично підхоплюється при старті `main.py`
(`core/commands_loader.py` об'єднує його зі старими командами з
`commands.yaml`).

### Або через вікно (GUI)

Запусти:
```
python gui/jarvis_settings.py
```
Вкладка **"Команди"** — додавай/редагуй/видаляй команди кнопками,
не чіпаючи yaml руками. Тут же вкладка **"Налаштування"** — мова
відповіді (uk/ru), Telegram api_id/api_hash, YouTube API key.

**Зібрати окремий `JarvisSettings.exe`** (робити на Windows, бо
PyInstaller збирає під ту ОС, на якій запущений):
```
pyinstaller gui.spec
```
Готовий exe буде в `dist/JarvisSettings/JarvisSettings.exe`.

## 2. Справжній ШІ-агент (не тільки розмова)

Раніше AI-режим (Gemini) міг тільки відповідати на питання. Тепер
доданий **`core/ai/agent.py`** — він спочатку розпізнає, чи це задача,
і якщо так — виконує її:

- **"напиши в групу Родина що я буду пізніше"** → надсилає повідомлення
  в Telegram
- **"знайди мені на ютубі плейлист з ембіент треками"** → шукає і
  відкриває плейлист на YouTube

Якщо команда — не задача, а звичайне питання, асистент просто
відповідає (як і раніше).

### Налаштування Telegram

Через звичайного бота довелось би додавати бота в кожну групу вручну.
Замість цього використано **Telethon** — він логіниться під ТВОЇМ
акаунтом (як звичайний Telegram-клієнт) і може писати в будь-яку
групу, де ти вже перебуваєш.

1. Зайди на https://my.telegram.org → "API development tools"
2. Створи застосунок, отримаєш `api_id` (число) і `api_hash` (рядок)
3. Впиши їх у `config.yaml`:
   ```yaml
   telegram:
     api_id: 123456
     api_hash: "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
   ```
   (або через GUI, вкладка "Налаштування")
4. Перший запуск команди "напиши в ..." попросить код підтвердження
   з Telegram — введи його прямо в консоль. Далі створюється файл
   сесії, повторний вхід більше не знадобиться.

⚠ Це діє від твого особистого акаунта — став тільки свій `api_id`,
нікому його не давай, і не використовуй для масової розсилки/спаму.

### Налаштування YouTube (опційно)

Без ключа асистент просто відкриє сторінку пошуку YouTube з потрібним
запитом. Якщо хочеш, щоб він одразу відкривав конкретний плейлист:

1. Google Cloud Console → увімкни "YouTube Data API v3" → створи
   безкоштовний API-ключ
2. Впиши в `config.yaml`:
   ```yaml
   youtube:
     api_key: "твій_ключ"
   ```

## 3. Ті самі голосові семпли

`assets/voice/*.wav` (да_сэр, есть, спасибо, загружаюсь,
запрос_выполнен) тепер програються замість/поруч із TTS у ключових
моментах (`core/sound.py`): активація по wake word, підтвердження
виконання команди, старт асистента.

## 4. Оригінальні репліки (не з фільму)

`phrases.yaml` — усі репліки асистента (привітання, "слухаю",
повідомлення про помилки тощо) українською і російською. Це
**оригінальні фрази**, написані для цього проєкту, а не цитати з
фільму (дослівні репліки персонажа Jarvis з "Iron Man" захищені
авторським правом). Мову відповіді обираєш у
`config.yaml → assistant.voice_language: uk` / `ru`.

## 5. Розпізнавання uk + ru одночасно

`core/stt.py` тепер вміє паралельно слухати кількома Vosk-моделями і
брати найкращий результат. Українська модель за замовчуванням не
завантажена (у репозиторії RustamovAkrom її не було) — довантаж
`vosk-model-small-uk-v3` з https://alphacephei.com/vosk/models,
розпакуй у `models/small/vosk-uk`. Поки її немає — асистент просто
працює тільки з російською моделлю, нічого не ламається.
